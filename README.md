# RO3 Thai Localization

แพตช์ภาษาไทยสำหรับ **RO3 Asia เวอร์ชัน PC**
ที่มุ่งปรับปรุงคำอธิบายสกิล ไอเทม เอฟเฟกต์ และข้อความที่เกี่ยวข้องให้อ่านง่าย
เป็นธรรมชาติ และรักษาความหมายเชิงกลไกของเกม

> [!IMPORTANT]
> โปรเจกต์นี้อยู่ระหว่างการพัฒนาและทดสอบ
> ยังไม่มีเวอร์ชันสำหรับติดตั้งหรือ Release อย่างเป็นทางการ

## เป้าหมายของโปรเจกต์

- แปลคำอธิบายสกิลและเอฟเฟกต์ใหม่จากต้นฉบับภาษาอังกฤษ
- แปลคำอธิบายไอเทมใหม่ทั้งหมด รวมถึงรายการที่เคยมีคำแปลแล้ว
- รักษาสูตร ตัวแปร placeholder และ style marker ของเกมให้ครบถ้วน
- ใช้คำศัพท์ค่าสถานะและกลไกการต่อสู้ให้สม่ำเสมอ
- คงชื่อสกิล ไอเทม มอนสเตอร์ แผนที่ คลาส และชื่อเฉพาะที่ผู้เล่นใช้ค้นหาในเกมเป็นภาษาอังกฤษ
- แจกตัวติดตั้ง Windows แบบไฟล์ `.exe` เดียว โดยไม่ใช้ไฟล์ `.bat`

## สถานะปัจจุบัน

| ส่วนงาน | สถานะ |
| --- | --- |
| แปลคำอธิบายสกิลและไอเทมใหม่ | กำลังดำเนินการ |
| ตรวจ placeholder และคำศัพท์ | กำลังดำเนินการ |
| ตัวติดตั้ง Windows แบบไฟล์เดียว | อยู่ระหว่างพัฒนา |
| ทดสอบภายในเกม | ยังไม่เริ่ม |
| Release สาธารณะ | ยังไม่มี |

จะยังไม่มีการสร้าง Release จนกว่าคำแปล ตัวติดตั้ง การอัปเดต การซ่อมแซม และการถอนการติดตั้งจะผ่านการทดสอบ

## ขอบเขตคำแปล

เน้นข้อความต่อไปนี้:

- คำอธิบายสกิล
- คำอธิบายเอฟเฟกต์ บัฟ และดีบัฟ
- คำอธิบายไอเทม อาหาร และยา
- ข้อความที่อธิบายสูตร ระยะเวลา เงื่อนไข และกลไกการต่อสู้

โดยทั่วไปจะคงข้อความต่อไปนี้เป็นภาษาอังกฤษ:

- ชื่อสกิลและไอเทม
- ชื่อมอนสเตอร์ NPC สัตว์เลี้ยง แผนที่ อาวุธ และคลาส
- ชื่อสถานะหรือกลไกเฉพาะ เช่น `Endure` และ `Control Immunity`
- ค่าสถานะ เช่น `P.ATK`, `M.ATK`, `P.DEF`, `M.DEF`, `ASPD`, `MSPD`, `CRIT` และ `Flee`

## หลักการรักษาข้อมูลเกม

คำแปลทุกข้อความต้องรักษาจำนวนและลำดับของข้อมูลสำคัญจากต้นฉบับ เช่น:

- `${1}`, `@{1}`, `{1}` และ placeholder อื่น
- `^{1}`, `^{2}` และ style marker
- เครื่องหมายคำนวณ เช่น `*`, `+` และ `%`
- การขึ้นบรรทัดใหม่ เช่น `\n`
- ชื่อเฉพาะภายในวงเล็บ

ชื่อสถานะที่ต้นฉบับใช้รูปแบบ `【Name】` หรือ `[Name]` จะแสดงเป็น `[ Name ]`

## ตัวติดตั้งสำหรับผู้ใช้

ตัวติดตั้งรุ่นใหม่จะเป็นไฟล์เดียว:

```text
RO3-Thai-Patch-Installer.exe
```

ขั้นตอนที่วางแผนไว้:

1. เปิดตัวติดตั้ง
2. เลือกโฟลเดอร์ `Client` ที่มีไฟล์ `ro3.exe` หรือเลือก `ro3.exe` โดยตรง
3. โปรแกรมตรวจสอบโฟลเดอร์ที่เลือก โดยไม่สแกนค้นหาเกมทั้งเครื่อง
4. เลือกติดตั้ง อัปเดต ซ่อมแซม หรือถอนการติดตั้ง
5. รอจนแถบความคืบหน้าเสร็จสมบูรณ์

ตัวติดตั้งจะไม่มีหน้าต่าง CMD และไม่ต้องเปิดไฟล์ `.bat`

## สำหรับนักพัฒนา

โปรเจกต์จะจัดให้มีขั้นตอนตรวจสอบอัตโนมัติก่อนนำคำแปลไปใช้:

1. อ่านข้อความจากคอลัมน์ต้นฉบับภาษาอังกฤษเท่านั้น
2. เขียนคำแปลใหม่โดยไม่อ้างอิงคำแปลอัตโนมัติเดิม
3. ตรวจ placeholder, style marker และชื่อเฉพาะ
4. ตรวจคำศัพท์มาตรฐานของโปรเจกต์
5. สร้าง payload สำหรับทดสอบ
6. ทดสอบการติดตั้ง อัปเดต ซ่อมแซม และถอนการติดตั้ง
7. ตรวจผลภายในเกมก่อนสร้าง Release

คำสั่ง build และโครงสร้างซอร์สโค้ดโดยละเอียดจะเพิ่มหลังจากย้ายระบบคำแปล
และตัวติดตั้งเข้าสู่ repository นี้เรียบร้อยแล้ว

## การทดสอบ

ก่อนเผยแพร่ต้องตรวจอย่างน้อย:

- คำแปลแสดงผลโดยไม่ทำให้ตัวแปรหรือสูตรเสียหาย
- ชื่อเฉพาะและค่าสถานะยังค้นหาในเกมได้
- ตัวติดตั้งเลือกโฟลเดอร์ผิดแล้วไม่เขียนไฟล์
- การติดตั้งซ้ำเปลี่ยนเป็นโหมดอัปเดตหรือซ่อมแซมอย่างถูกต้อง
- การถอนการติดตั้งไม่ลบ BepInEx หรือม็อดที่มีอยู่ก่อนติดตั้งแพตช์
- เกมสามารถเปิดและแสดงคำแปลได้หลังติดตั้ง

## รายงานปัญหา

เมื่อระบบทดสอบพร้อม กรุณาแนบข้อมูลต่อไปนี้เมื่อต้องการรายงานปัญหา:

- ข้อความภาษาอังกฤษต้นฉบับ
- คำแปลที่แสดงในเกม
- ภาพหน้าจอ
- ขั้นตอนที่ทำให้เกิดปัญหา
- Log จากตัวติดตั้ง หากเป็นปัญหาด้านการติดตั้ง

## ข้อจำกัดความรับผิดชอบ

โปรเจกต์นี้เป็นผลงานชุมชนและไม่ใช่แพตช์อย่างเป็นทางการของผู้พัฒนาเกม
ชื่อเกม เครื่องหมายการค้า และทรัพย์สินที่เกี่ยวข้อง
เป็นของเจ้าของลิขสิทธิ์แต่ละราย
