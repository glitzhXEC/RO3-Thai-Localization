# Map and monster name audit

ตรวจตาราง runtime ครบ **33,513 IDs** เทียบกับชื่อจาก catalog แผนที่/ฉาก 190 ชื่อ และ catalog มอนสเตอร์/สัตว์เลี้ยง 220 ชื่อ โดยตรวจทั้งชื่อเดี่ยวและชื่อที่อยู่ในประโยคไทย

## ผลตรวจ

- คืนชื่อแผนที่/สถานที่ที่ถูกแปลเป็นไทย 13 IDs ให้เป็น English โดยลบออกจาก batch แปล
- ชื่อในประโยค เช่น `Deep Forest`, `Payon Forest`, `Ant Hell`, `Golden Thief Bug`, `Eddga`, `Maya` และ `Pharaoh` ยังคง English
- ไม่พบชื่อมอนสเตอร์ที่ยืนยันได้ว่าถูกแปลเป็นไทยในตารางปัจจุบัน
- คำทั่วไปที่สะกดเหมือนชื่อมอนสเตอร์ เช่น `drops`, `familiar`, `nightmare`, `whisper`, `clock`, `horn` และ `wolf` ไม่ถูกจัดเป็นความผิดเมื่อบริบท English ใช้เป็นคำนามหรือคำกริยาทั่วไป

## กฎที่ใช้

ชื่อแผนที่ ดันเจี้ยน เมือง โซน สถานที่ มอนสเตอร์ บอส NPC และสัตว์เลี้ยงต้องคง English ตรงต้นฉบับทุกตัว แปลได้เฉพาะข้อความรอบชื่อ หากไม่แน่ใจว่าเป็นชื่อเฉพาะหรือคำทั่วไป ให้คง English และแยกตรวจบริบท ห้ามเดาแปล
