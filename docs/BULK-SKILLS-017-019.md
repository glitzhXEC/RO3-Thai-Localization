# คำแปลสกิลชุดใหญ่ 017–019

เพิ่มใหม่ 209 รายการจาก English เท่านั้น แล้วรวมอัปหลังตรวจเสร็จ

- คำอธิบายสกิลหลัก/สัตว์เลี้ยง 99 รายการ
- เอฟเฟกต์/บัฟ/ดีบัฟ 110 รายการ

ครอบคลุม Madogear, พาหนะ, Fafnir, การควบคุม, Goat, Geographer, Bongun, Choco, Nightmare, Clock, Sohee และผลของ Primary Battle Skills

## การตรวจแก้

ตรวจสูตรฮีลที่อิง Adaptive ATK ให้เป็นจำนวน HP ที่ฟื้นฟู ไม่เติมความหมายว่าเป็นเปอร์เซ็นต์ของ HP/Max HP ที่ English ไม่ได้ระบุ

คงทุกตัวแปร style marker ตัวเลข สูตร และชื่อสกิล/สถานะตาม English รวมต้นฉบับที่ใช้ M.ATK คำนวณดาเมจกายภาพ ไม่เปลี่ยนชนิดดาเมจเอง รายการต้นฉบับที่สูตรไม่ครบหรือคำกำกวมยังอยู่ในคิว ไม่เดาแก้ เช่น `10110300508`

ชุด 019 ใช้คำแปลใหม่กับอีก 2 IDs ที่ English ทั้งประโยคตรงกันทุกตัวอักษรเท่านั้น ไม่ใช้คำแปลเก่าและไม่แทนคำทั่วทั้งเกม

## ผลตรวจและสถานะ

ซอร์สคำแปลรวม 1,415 รายการ เหลือคิวสำคัญ 2,002 รายการ ชุดสกิลจากซอร์สมี 1,070 IDs / 662 rules

ตรวจตัวแปร สูตร newline วงเล็บชื่อ และโครงสร้าง TSV ผ่าน ไม่มี structural error ทดสอบข้อความจำลองผ่าน 4,542 checks และตรวจ validation ด้วยการจงใจทำตัวแปร/เครื่องหมายคูณ/ชื่อในวงเล็บผิดผ่าน

ยังไม่ทดสอบรายการใหม่ในเกมจริง **ยังไม่รวมใน EXE `v0.2.0-skills-alpha.1`** ซึ่งบรรจุ 416 IDs การอัป repo ไม่อัปแพตช์ในเครื่องผู้ใช้โดยอัตโนมัติ

อย่านำ Overrides รวมไปแทนไฟล์สกิลโดยตรง และอย่าแก้ไฟล์ที่ตัวติดตั้งเป็นเจ้าของเองโดยไม่อัปเดต ownership/hash
