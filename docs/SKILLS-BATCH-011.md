# คำแปลสกิลชุด 011

เพิ่มคำแปลใหม่ 55 รายการจาก English เท่านั้น: Falcon, กับดัก, ธนู, Demonic Wolf และสกิลบอสบางส่วน

รวม `10110300403` และ `10110300407` ซึ่งตรงกับคำอธิบายสกิลธนูที่ผู้ใช้ส่งภาพมา โดยรุ่นมีสูตรบวกค่าคงที่ใช้ `10110300403`

## สถานะ

- คำแปลในซอร์สรวม 816 รายการ
- ชุดสกิลที่เตรียมจากซอร์สได้ 471 IDs / 236 rules
- ตรวจ placeholder, style marker, ตัวเลข, เครื่องหมายสูตร, วงเล็บชื่อ และ newline ผ่าน
- ทดสอบ dictionary/rules ด้วยค่าจำลองผ่าน 1,893 checks
- ไม่มีการนำคำแปลเดิมมาใช้
- ยังไม่ทดสอบรายการใหม่ในเกมจริง

**คำแปลชุดนี้ยังไม่รวมอยู่ใน EXE ของ `v0.2.0-skills-alpha.1`** รุ่นที่ปล่อยแล้วมี 416 IDs การอัปเดตไฟล์ใน repo ไม่เปลี่ยนแพตช์ที่ติดตั้งไว้บนเครื่องผู้ใช้โดยอัตโนมัติ

อย่านำไฟล์ Overrides รวมไปแทน SkillTranslations โดยตรง: Overrides รวมไอเทมด้วย ส่วนตัวแสดงสกิลใช้ชุดที่กรองและตรวจแล้ว พร้อม runtime rules หากแก้ไฟล์ที่ตัวติดตั้งเป็นเจ้าของเอง อาจทำให้ตรวจ hash ตอนถอนแพตช์ไม่ผ่าน
