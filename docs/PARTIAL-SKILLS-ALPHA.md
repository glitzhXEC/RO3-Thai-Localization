# แพตช์สกิลบางส่วน — Alpha 0.2.0

รุ่นนี้บรรจุ payload และติดตั้งไฟล์ได้ ไม่ใช่ UI Preview แต่ **ยังไม่ได้ยืนยันการเปิดเกมหรือการแสดงผลในเกมจริง**

## ขอบเขต

- บรรจุคำแปลใหม่ 416 รหัสของสกิล เอฟเฟกต์ และเสริมสกิล
- ใช้ English เท่านั้น ไม่ใช้คำแปลเก่า
- เพิ่มคำแปลใหม่ 70 รายการในชุด 009/010 เน้น Madogear, หอก, โล่, Crusader และสถานะควบคุม
- ไม่มี global word replacement หรือบริการแปลออนไลน์
- ข้อความที่ไม่ตรงคำแปลที่อนุมัติจะคงเดิม ควรตั้งภาษาเกมเป็น English
- แยกข้อความกำกวมออกจาก payload รวมสูตร `+ *` ที่ไม่ชัดเจน ไม่แก้สูตรเอง

## ติดตั้งสำหรับทดสอบ

รองรับเฉพาะ RO3 PC **Windows x64 / Unity Mono** รุ่น Alpha นี้ใช้กับ Client ที่ยังไม่มี BepInEx หรือ winhttp.dll เดิมเท่านั้น **ไม่รองรับการติดตั้งทับแพตช์เก่าหรือม็อดเดิม**

1. ปิดเกมและ RO3AsiaLauncher
2. เปิด `RO3-Thai-Patch-Installer.exe`
3. เลือกโฟลเดอร์ `Client` ที่มี `ro3.exe` หรือเลือกไฟล์ `ro3.exe` โดยตรง
4. โปรแกรมตรวจเฉพาะตำแหน่งที่เลือก รวม PE x64 และ `ro3_Data/Managed/UnityEngine.CoreModule.dll` โดยไม่ค้นหาเครื่อง/โฟลเดอร์อื่น
5. หากถูกต้องและไม่มี runtime เดิม ปุ่มติดตั้งจะเปิดทำงาน
6. กดติดตั้ง รอ Progress และผลตรวจ hash
7. เปิดเกมด้วย Launcher ปกติ ตรวจคำอธิบายสกิลที่อยู่ในรายการ payload

เมื่อพบ BepInEx/ม็อดเดิม ให้หยุด ไม่ลบทั้งโฟลเดอร์โดยเดาเพื่อบังคับติดตั้ง Alpha

## ถอนแพตช์

ปิดเกม/Launcher เปิด EXE เดิม เลือก Client แล้วกด **ถอนแพตช์นี้**

- ตรวจ ownership และ hash ก่อนลบ
- คืนไฟล์เดิมจาก backup ถ้ามี
- ไม่ลบไฟล์/ม็อดที่เพิ่มภายหลัง
- เก็บ snapshot ก่อนถอน รวม config ที่มีการเปลี่ยนแปลง
- หาก DLL/ไฟล์คำแปลถูกแก้เอง จะหยุดเพื่อป้องกันข้อมูลสูญหาย
- log และไฟล์อื่นที่ runtime สร้างภายหลังอาจเหลืออยู่ จึงยังไม่รับประกันติดตั้งซ้ำ/อัปเดตทับใน Alpha นี้

## Runtime

ใช้ BepInEx 5.4.23.5 / XUnity 5.6.2 compatibility components จาก bundle ของ repo เดิมที่ล็อก SHA256 ไว้ เพื่อไม่แทนด้วย official runtime ที่ยังไม่ได้ยืนยันว่าเข้ากันได้กับ RO3

นำมาเฉพาะ core DLL, XUnity components, config ระบบ และฟอนต์ ไม่อ่าน/นำคำแปลเดิม alias หรือ `RO3.LocalizationTablePatcher.dll` เก่ามาใช้ Plugin `RO3.ThaiLocalization.Skills.dll` และ engine เป็นโค้ดใหม่ อ่านเฉพาะข้อมูลสกิลที่เขียนใหม่

รายละเอียด provenance อยู่ใน `runtime-provenance.json` และ license ถูกบรรจุไว้ใน payload ไม่มี BAT/Translation-Editor และไม่แก้หรือ bypass anti-cheat

## ผลตรวจที่ทำแล้ว

- ตรวจ placeholder, style marker, ตัวเลข, สูตร, วงเล็บชื่อ และ newline
- Runtime dictionary/rules ผ่าน 1,636 checks ด้วยค่าจำลอง ทั้งมี/ไม่มี rich-text markup
- ตัวติดตั้งผ่าน 34 checks รวมติดตั้ง payload จริงลงโฟลเดอร์จำลอง ถอน คืนไฟล์เดิม และรักษาม็อดที่เพิ่มภายหลัง
- Compile plugin และ EXE Windows สำเร็จ

ผลเหล่านี้ **ไม่ใช่การทดสอบ GUI หรือเกมจริง** หากไม่ขึ้นไทย/เห็นสี่เหลี่ยม กรุณาส่งภาพสกิลพร้อม English ต้นฉบับ และ `Client/BepInEx/LogOutput.log` โดยปิดบังข้อมูลส่วนตัวก่อน

EXE ยังไม่มี code signing ให้ตรวจแหล่งดาวน์โหลดและ SHA256 ไม่ต้องปิดระบบป้องกันเครื่องเพื่อทดลอง และควรตรวจข้อกำหนดของเกมก่อนใช้ม็อด
