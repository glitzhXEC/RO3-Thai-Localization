# คำแปลสกิลชุดใหญ่ 023–026

เพิ่มคำแปลใหม่ 241 รายการจาก English เท่านั้น แล้วรวมอัปหลังตรวจเสร็จ

## ขอบเขต

สกิลเสริม Mage, เอฟเฟกต์ Assassin/Knight/Priest, สกิลเงา, เพลงและจังหวะดันเจี้ยน, ผลของ Protector, โล่, คำสาป และการคำนวณ Adaptive ATK

สัดส่วนตามตระกูล ID: {"skill-enhancement": 29, "skill-description": 7, "skill-effect": 205}

ชุด 026 ใช้คำแปลใหม่กับอีก 7 IDs ที่ English ทั้งประโยคตรงกันทุกตัวอักษรเท่านั้น ไม่มีคำแปลเก่าหรือการแทนคำทั่วทั้งเกม

## การตรวจแก้

- แปล dual-wielding daggers เป็นถือมีดคู่ ไม่ใช่มีดสองมือ
- คงชนิดดาเมจที่ English ระบุ แม้ใช้ M.ATK คำนวณดาเมจกายภาพ ไม่เดาแก้สูตร
- ไม่สลับ HP กับ Max HP และไม่เพิ่มคำอธิบายเวลาหรือค่าความเสียหายที่ต้นฉบับไม่ได้ระบุ
- คงตัวแปร style marker สูตร ชื่อในวงเล็บ และ escaped newline ครบ
- เลือกข้อความเอฟเฟกต์ที่ใช้กับผู้เล่นก่อน ปล่อยข้อความ designer-only และต้นฉบับที่ค่าไม่ครบไว้ในคิว เช่น `${2}% sec` หรือ `*value description* ... x seconds` ไม่เดาแก้หน่วยและค่า

## ผลตรวจและสถานะ

ซอร์สคำแปลรวม 1,874 รายการ เหลือคิวสำคัญ 1,543 รายการ ชุดสกิลจากซอร์สมี 1,529 IDs / 989 rules

ตรวจตัวแปร ตัวเลข สูตร newline วงเล็บชื่อ และโครงสร้าง TSV ผ่าน ไม่มี structural error ทดสอบข้อความจำลองผ่าน 6,573 checks และตรวจ validation ด้วยการจงใจทำตัวแปร/เครื่องหมายคูณ/ชื่อในวงเล็บผิดผ่าน

ยังไม่ทดสอบรายการใหม่ในเกมจริง **ยังไม่รวมใน EXE `v0.2.0-skills-alpha.1`** ซึ่งมี 416 IDs การอัป repo ไม่อัปแพตช์ที่ติดตั้งบนเครื่องผู้ใช้โดยอัตโนมัติ
