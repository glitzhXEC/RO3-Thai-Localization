# คำแปลสกิลชุดใหญ่ 020–022

เพิ่มคำแปลใหม่ 218 รายการจาก English เท่านั้น แล้วรวมอัปหลังตรวจเสร็จ

## ขอบเขต

Totem, ธาตุเกราะ, ค่าสถานะ/การฟื้นฟู, สกิลเสริมสาย Thief, Archer/Falcon, ผลบัฟและเอฟเฟกต์การต่อสู้

สัดส่วนตามตระกูล ID: {"skill-effect": 118, "skill-enhancement": 100}

ชุด 022 ใช้คำแปลใหม่กับอีก 1 ID ที่ English ทั้งประโยคตรงกันทุกตัวอักษรเท่านั้น ไม่มีคำแปลเก่าหรือการแทนคำทั่วทั้งเกม

## ตรวจความหมาย

- คงสูตร Character Lv. / your Lv. และตัวแปรในวงเล็บ ไม่แทนด้วยค่าที่เดา
- ไม่เติม ATK เข้าในสูตรดาเมจที่ English ระบุเพียงเปอร์เซ็นต์กับค่าคงที่
- แยกดาเมจส่วนค่าคงที่ออกจากความหมายดาเมจที่ข้ามการป้องกัน
- ไม่เติมข้อจำกัดการซ้อนบัฟที่ต้นฉบับ Unique Effect ไม่ได้ระบุ
- แปล Floors เป็นชั้น และคงคำ stacks เมื่อ English ใช้ stacks

## ผลตรวจและสถานะ

ซอร์สคำแปลรวม 1,633 รายการ เหลือคิวสำคัญ 1,784 รายการ ชุดสกิลจากซอร์สมี 1,288 IDs / 835 rules
