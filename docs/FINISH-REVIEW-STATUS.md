# สถานะงานแปลใหม่หลังชุด 027–033

## สรุปที่ตรวจได้จริง

- คิวเป้าหมายสกิล/ไอเทม: 3,417 รายการ ไม่ใช่ข้อความทั้งหมดของเกม
- คำแปลในตารางใช้งาน: **2,265 รายการ** เพิ่ม 391 รายการจากชุด 026
- สกิลในชุดโหลดจากซอร์ส: 1,800 IDs / 1,121 rules
- ทดสอบชุดโหลดจากซอร์ส: 7,650 checks ผ่าน ไม่ได้รันเกม
- ร่างยังไม่ตรวจความหมาย: **1,121 รายการ** แยกใน translations/drafts ไม่รวมในตารางใช้งาน
- ต้นฉบับไม่ครบ/กำกวม/ภายใน: **31 รายการ** ดู translations/review/withheld-source.json
- คิวคงเหลือรวม: **1,152 รายการ**

**ยังแปลไม่เสร็จในระดับพร้อมใช้งาน แม้จัดทำร่างครอบคลุมคิวแล้ว**

028: เขียนใหม่และแก้กลไกจาก English ของร่างที่ไม่ผ่าน 25 รายการ
029: เวท Mage, Gravitation Field, สถานะและบัฟ 91 รายการ
030: ไอเทม วัตถุดิบ เพาะปลูก ขุดแร่ และกล่องรางวัล 110 รายการ
031: ธนู Warlock สกิลบอส สัตว์เลี้ยง และการกระทำในกิจกรรม 99 รายการ

033: ใช้คำแปลใหม่ที่ตรวจแล้วกับ English ที่เหมือนกันทุกตัว 1 รายการ ไม่มีการใช้คำแปลไทยเก่า

แก้ inflict เป็นทำให้ติดสถานะ ไม่ใช่สร้างดาเมจ, master เป็นเจ้าของ, fixed damage เป็นดาเมจค่าคงที่ และรักษาเงื่อนไขการเกิดผล เป้าหมาย ตัวเลข สูตร ตัวแปรและลำดับเครื่องหมายไว้

แก้อักษรเสียใน 10110300843 และ 10110301091 พร้อมเพิ่มตัวตรวจ replacement character และ marker จากเครื่องมือร่าง ตรวจโครงสร้างผ่าน แต่การผ่านทดสอบไม่ได้รับประกันการแสดงผลในเกมหรือคุณภาพทุกข้อความ

## เครื่องมือช่วยร่างและข้อจำกัด

ใช้ English สาธารณะเท่านั้น ไม่ใช้ Thai เดิม ร่างที่ยังไม่ตรวจใช้ Google Translate public endpoint ระหว่างจัดทำคำแปล ไม่มีการเปิดแปลออนไลน์ในเกม ร่างแม้รักษาตัวแปรครบยังมีข้อผิดพลาดด้านกลไก จึงไม่อนุมัติทั้งหมดอัตโนมัติ

ต้นฉบับ Reply HP ไม่ถูกเดาเป็น Restore HP และสูตร Physical ATK*^{1} ที่ขาดค่าดาเมจแยกไว้ตรวจ

## EXE และ Release

รุ่น v0.2.0-skills-alpha.1 ยังบรรจุ 416 IDs ไม่ได้รับคำแปลใหม่จาก main โดยอัตโนมัติ ไม่มีการสร้าง EXE/Release ใหม่ในชุดนี้ ห้ามคัดลอกตารางซอร์สทั้งหมดทับ RO3.SkillTranslations.tsv เพราะตารางรวมไอเทมด้วย และตัวติดตั้ง/ถอนติดตั้งตรวจ hash ของไฟล์ที่ดูแลอยู่

งานต่อไป: ตรวจความหมายร่างที่เหลือทีละแถว แก้ต้นฉบับกำกวมหลังยืนยัน English แล้วจึงสร้างตัวติดตั้งและทดสอบ Windows/เกมจริง
