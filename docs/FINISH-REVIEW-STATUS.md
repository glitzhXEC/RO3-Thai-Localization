# สถานะล่าสุด: คิวคำอธิบายสกิลและไอเทม

## ผลงานชุด 034–045

แปลและตรวจเทียบ English เพิ่ม **1,115 รายการ** ไม่ใช้คำแปลไทยเก่า คำแปลในตารางซอร์สรวม **3,380 รายการ**

- คิวเป้าหมาย: 3,417 รายการ ไม่ใช่ข้อความทั้งหมดของเกม (33,512 รายการใน English snapshot)
- คำแปลที่ข้อมูลครบ/แปลตามต้นฉบับได้ในคิวร่าง: ตรวจและเขียนใหม่ครบแล้ว ไม่มีร่างที่ยังไม่ตรวจเหลือ
- ต้นฉบับไม่ครบ กำกวม หรือระบุให้ไม่ใช้: **37 รายการ** ยังกันไว้พร้อมเหตุผลใน translations/review/withheld-source.json และ pending-queue.tsv
- สกิลจากซอร์ส: **2,414 IDs / 1,621 rules**
- ทดสอบโหลดสกิลและแทนค่าตัวเลข/สี: **10,492 checks ผ่าน** ไม่ได้รันเกม
- ตรวจลำดับ placeholder ตัวเลข สูตร เครื่องหมาย % * + ชื่อในวงเล็บ จำนวนบรรทัด อักษรเสีย และ marker จากเครื่องมือร่าง: ผ่าน
- การตรวจโดยผู้ตรวจภาษาอิสระและการทดสอบเกมยังไม่เสร็จ ผลทดสอบโครงสร้างไม่รับประกันความสมบูรณ์ด้านภาษา/การแสดงผลทุกกรณี

## ขอบเขตคำแปลใหม่

034–037: ไอเทม 501 รายการ ครอบคลุมวัตถุดิบ อาวุธ เกราะ ไอเทมกิจกรรม ของขวัญ เงินตรา และการตีบวก
038–045: สกิล/คำอธิบายกิจกรรม 614 รายการ ครอบคลุมสัตว์เลี้ยง Knight/Crusader/Rune Knight, Assassin/Guillotine Cross, Mage/Warlock, Archer/Warg, Madogear และกลไกบอส

ข้อความป้ายระบบภายใน/TBD/Deprecated บางแถวแปลตามตัวอักษรพร้อมคงสถานะของต้นฉบับ ไม่ใช่สกิลใหม่ทั้งหมด ไม่เติมหน่วย ค่า หรือกลไกที่ English ไม่มี

แก้ตัวคั่นสีของ 10110300630 โดยคงขอบเขต style ที่ติดกันก่อนทดสอบซ้ำ ไม่แก้ validator ให้ยอมรับสูตรเสีย

## รายการที่ยังกันไว้

คิวคงเหลือ 37 รายการไม่ได้ถูกเดาเติม เช่นดาเมจ x/A, สูตรที่ขาดค่า, Reply HP ที่ไม่แน่ชัด, bracket ซ้อนผิดรูป และสตริงที่ระบุไม่ใช้/ทดสอบ

รายการ semantic-review เดิม 5 IDs ยังคงถูกกันออกจากชุดสกิล: 10110300015, 10110300017, 10110300134, 10800100011, 12390100679 รายละเอียดอยู่ใน translations/semantic-review.json จึงไม่ควรตีความจำนวนคำแปลซอร์สว่าเป็นจำนวนที่ติดตั้งได้ทั้งหมด

## ตารางและ EXE

RO3.LocalizationOverrides.tsv และ retranslated.tsv เป็นตารางสร้างจาก batch ที่ตรวจแล้วเท่านั้น โฟลเดอร์ drafts ว่างและไม่รวมใน runtime

ตารางซอร์สมีขนาดเกินขีดจำกัดการส่ง payload ทาง MCP หนึ่งครั้ง จึงใช้ workflow Refresh translation tables บน GitHub สร้างตารางจาก batch ใน repo หลังผ่าน validator และ runtime tests แล้ว commit กลับ main ไม่มีการเพิ่ม secret หรือเปิดบริการแปลออนไลน์

EXE v0.2.0-skills-alpha.1 เดิมยังบรรจุ 416 IDs ไม่มีการสร้าง EXE/Release ใหม่ในชุดงานแปลนี้ คำแปลบน main ไม่เปลี่ยน EXE ที่ดาวน์โหลดแล้วโดยอัตโนมัติ ห้ามคัดลอกตารางซอร์สทั้งหมดทับ RO3.SkillTranslations.tsv เพราะ schema/ขอบเขตต่างกันและตัวติดตั้งตรวจ hash ของไฟล์
