RO3 Thai Patch — Windows x64 UI Preview

สำคัญ: รุ่นนี้ยังติดตั้งแพตช์ภาษาไทยไม่ได้
ไม่มี BepInEx/runtime payload อยู่ใน EXE และปุ่มติดตั้งจะไม่เปิดใช้งาน
คำแปล 691 รายการยังต้องตรวจความหมายและทดสอบในเกม

ใช้ทดสอบ:
1. เปิด RO3-Thai-Patch-Installer.exe บน Windows x64
2. กดเลือกโฟลเดอร์เกม แล้วเลือก Client ที่มี ro3.exe
3. หรือเลือกไฟล์ ro3.exe โดยตรง
4. ตรวจข้อความแจ้งเตือนเมื่อเลือกถูก/ผิด
5. ไม่มีการค้นหาเกมอัตโนมัติ และรุ่นนี้ไม่เขียนแพตช์ลงเกม

EXE รวม .NET runtime แล้ว ไม่ต้องเปิด BAT
ยังไม่ได้ทดสอบหน้าจอในเครื่อง Windows ของผู้ใช้ และยังไม่ผ่านการทดสอบเกม
EXE ไม่มีลายเซ็น code signing อาจมีคำเตือนของ Windows ให้ตรวจแหล่งดาวน์โหลดและ SHA256 ก่อนใช้งาน ไม่จำเป็นต้องปิดระบบป้องกันเพื่อทดสอบ
