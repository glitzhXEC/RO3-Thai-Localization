# คำแปลสกิลชุดใหญ่ 012–016

แปลใหม่รวม 390 รายการ แล้วค่อยรวมอัปขึ้น repo ไม่ได้ปล่อยทีละชุดเล็ก

## ขอบเขต

- คำอธิบายสกิลหลัก 102 รายการ: เวทพื้นที่, Battle Royale, สกิลช่วยทีม, Madogear และสกิลบอส
- เอฟเฟกต์/บัฟ/ดีบัฟ 169 รายการ: Blacksmith, Crusader, การ์ด, การพรางตัว, การฮีล และดาเมจสะท้อน
- สกิลเสริม 119 รายการ: Priest, Crusader, Knight และบางสกิลสายโจร

คำแปลซอร์สรวม 1,206 รายการ ยังเหลือรายการในคิวสำคัญ 2,211 รายการ ไม่ใช่การแปลครบทั้งเกม

## วิธีและผลตรวจ

ยึด English จาก snapshot เท่านั้น ไม่อ่านหรือใช้คำแปลเก่า ใช้ชื่อสกิล/สถานะตาม English พร้อมค่าสถานะมาตรฐาน

ชุด 012, 013, 015 เขียนคำแปลใหม่ ชุด 014 ใช้คำแปลใหม่กับรหัสที่ English ทั้งประโยคตรงกันทุกตัวอักษรเท่านั้น ชุด 016 ใช้รูปประโยคเต็มที่เขียนกฎเฉพาะและเก็บ provenance ไม่มีการแทนคำทั่วทั้งเกมและไม่มีบริการแปลออนไลน์

ตรวจตัวแปร, style marker, ตัวเลข, เครื่องหมายสูตร, วงเล็บชื่อ, newline และโครงสร้าง TSV ผ่าน ไม่มี structural error ตรวจคำแปลเชิงกลไกของรายการใหม่ก่อนรวม และไม่เดาต้นฉบับที่ไม่ชัดเจน เช่นสูตรที่ตัวแปรไม่ปิดวงเล็บ

ชุด runtime ที่สร้างจากซอร์สได้ 861 IDs / 531 rules ทดสอบข้อความจำลองผ่าน 3,653 checks ทั้งข้อความดิบ/ค่าตัวเลข/rich-text ตรวจระบบ validation ด้วยการจงใจแก้ตัวแปร เครื่องหมายคูณ และชื่อในวงเล็บผ่าน

ยังไม่ได้ทดสอบรายการใหม่ในเกมจริง ผลทดสอบอัตโนมัติไม่ยืนยันการจับข้อความและฟอนต์ในทุก UI

## สถานะไฟล์ติดตั้ง

**ยังไม่รวมคำแปลใหม่ชุดนี้ใน EXE `v0.2.0-skills-alpha.1`** รุ่นที่ปล่อยแล้วมี 416 IDs ส่วนตัวเลข 861 IDs เป็นชุดที่เตรียมจากซอร์สปัจจุบัน การอัป repo ไม่อัปเดตแพตช์ที่ติดตั้งบนเครื่องผู้ใช้โดยอัตโนมัติ

อย่านำ Overrides รวมไปแทน SkillTranslations โดยตรง เพราะรวมไอเทมและมีขอบเขตต่างกัน อย่าแก้ไฟล์ที่ตัวติดตั้งเป็นเจ้าของโดยไม่อัปเดต ownership/hash เพราะอาจทำให้การถอนแพตช์ตรวจไม่ผ่าน
