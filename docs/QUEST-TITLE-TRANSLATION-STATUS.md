# Quest title translation — batch 116

แปลชื่อเควสต์ที่เคยคงเป็น English เพิ่ม **39 IDs** จากคอลัมน์ English ปัจจุบันเท่านั้น ไม่ใช้คำแปลไทยเก่า

## ขอบเขต

- ชื่อเควสต์ 36 รายการในตระกูล `131501`
- ชื่อกิจกรรมเควสต์ที่ซ้ำกัน 3 รายการใน `131500`, `131502` และ `131504`
- คงชื่อคลาส เมือง และคำเกมที่ต้องค้นหาได้ เช่น `Novice`, `Swordsman`, `Payon`, `Academy` และ `Holy See` ไว้ในชื่อไทย
- รักษา placeholder และ style marker ทุกตัว เช่น `@{1}`, `^{1}` และ `^{2}`

## ยังไม่แปล

- ข้อความ `Utility` ที่ไม่ระบุว่าเป็นไอเทม ทรัพยากร หรือการช่วยเหลือ
- `Rift Stone*` ซึ่งเป็นชื่อไอเทมพร้อมเครื่องหมายต้นฉบับ
- `@{1}` ซึ่งเป็น placeholder ล้วน
- ป้ายประเภทเควสต์ในวงเล็บ เช่น `[Main Quest]` เนื่องจาก validator ปัจจุบันกำหนดให้ข้อความ protected bracket คงเดิม

รายการเหล่านี้ยังคง English เพื่อไม่เดาความหมาย ไม่ทำให้ชื่อไอเทมหายจาก UI และไม่เปลี่ยนข้อกำหนด validator ในชุดข้อมูลแปล
