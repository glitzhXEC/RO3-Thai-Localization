# ข้อกำหนดตัวติดตั้ง Windows

สถานะ: ข้อกำหนดเท่านั้น ยังไม่มี executable และยังไม่ทดสอบบน Windows

## ขั้นตอนผู้ใช้

1. เปิด `RO3-Thai-Patch-Installer.exe` โดยไม่มีหน้าต่าง CMD หรือไฟล์ `.bat`
2. แสดงช่องตำแหน่งเกม (ยังว่าง) พร้อมปุ่ม **เลือกโฟลเดอร์เกม**
3. ให้ผู้ใช้เลือกโฟลเดอร์ `Client` ที่มี `ro3.exe` โดยตรง
4. ตรวจเฉพาะ `Path.Combine(selectedFolder, "ro3.exe")` ว่าเป็นไฟล์จริง ห้ามตรวจโฟลเดอร์อื่น
5. เปิดปุ่ม **ติดตั้ง** เมื่อเลือกถูกต้องและ payload พร้อมเท่านั้น
6. หากไม่พบ แจ้ง **เลือกโฟลเดอร์ไม่ถูกต้อง: ไม่พบ ro3.exe** และปิดปุ่มติดตั้ง
7. เมื่อติดตั้ง แสดง Progress และสรุปผล/ข้อผิดพลาด ห้ามแสดงสำเร็จก่อนเขียนและตรวจไฟล์ครบ

เพิ่มปุ่ม **เลือกไฟล์ ro3.exe** ได้ โดยตรวจชื่อไฟล์ตรงกันแล้วใช้โฟลเดอร์แม่ ยกเลิกกล่องเลือกต้องไม่เปลี่ยนตำแหน่งเดิมหรือเปิดปุ่มติดตั้ง

## ข้อห้าม

- ห้ามค้นหาอัตโนมัติผ่าน drive, registry, launcher, process, recent folders หรือโฟลเดอร์มาตรฐาน
- ห้ามไล่ค้นหาในโฟลเดอร์ลูก ห้ามเลือก parent แล้วค้นหา Client ให้อัตโนมัติ
- ไม่บรรจุ `Translation-Editor` หรือ `.bat` ใน repository/release ใหม่
- ไม่รวมคำแปลเก่าหรือ online auto-translation เป็น fallback
- ห้ามเปิดเกมหรือข้าม anti-cheat เพื่อทดสอบ

## ความปลอดภัยของการติดตั้ง

- ให้ผู้ใช้ปิดเกมและ Launcher ก่อนติดตั้ง
- ตรวจ manifest/hash ของ payload และป้องกัน path traversal
- สำรองไฟล์เดิมก่อนทับ เก็บ ownership manifest เพื่อถอนเฉพาะไฟล์ที่แพตช์เป็นเจ้าของ
- ไม่ลบ BepInEx หรือม็อดเดิมของผู้ใช้
- รองรับ rollback เมื่อผิดพลาด และบอกข้อผิดพลาดเรื่องสิทธิ์/พื้นที่/ไฟล์ถูกใช้งาน
- ยกเลิกหรือเลือกโฟลเดอร์ผิดต้องไม่เขียนไฟล์ลงเครื่อง

## เกณฑ์ทดสอบ Windows ก่อน release

ทดสอบโฟลเดอร์ผิด, โฟลเดอร์ถูก, ชื่อ path ไทย/ช่องว่าง, เลือก exe, กดยกเลิก, read-only, disk full, install ซ้ำ, update, rollback, uninstall และการคงม็อดเดิมไว้ ต้องทดสอบเกมจริงแยกต่างหาก

การ build EXE และจัด payload จะเริ่มหลังงานแปล/ตรวจระบบพร้อม ไม่ถือไฟล์เอกสารนี้เป็นตัวติดตั้งที่ใช้งานได้
