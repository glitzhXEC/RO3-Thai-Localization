# ร่างคำแปลสำหรับตรวจเท่านั้น — ห้ามติดตั้ง

ไฟล์ในโฟลเดอร์นี้ยังไม่ได้ตรวจความหมายครบ ไม่ได้รวมใน RO3.LocalizationOverrides.tsv หรือ runtime payload และห้ามคัดลอกเข้า BepInEx

ร่างด้วยเครื่องมือช่วยแปลจาก English ที่เผยแพร่สาธารณะ โดยไม่อ่านหรือใช้คำแปลไทยเก่า เครื่องมือช่วยร่าง: Google Translate public endpoint (English → Thai) ใช้เฉพาะระหว่างจัดทำคำแปล ไม่ได้เปิดแปลออนไลน์ในเกม

การผ่านการตรวจตัวแปรไม่ได้รับประกันว่ากลไกสกิลถูกต้อง พบตัวอย่างการแปล inflict status ผิดเป็นสร้างดาเมจ, master ผิดเป็นอาจารย์ และ fixed damage ผิดเป็นแก้ไขดาเมจ จึงต้องตรวจทุกแถวก่อนย้ายเข้า batch ที่ใช้งาน

ดูสถานะจริงและจำนวนแถวล่าสุดที่ ../../docs/FINISH-REVIEW-STATUS.md
