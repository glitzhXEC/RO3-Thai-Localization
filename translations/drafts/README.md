# สถานะร่างคำแปล

ร่างที่ต้นฉบับครบในคิวเป้าหมายตรวจและเขียนคำแปลใหม่จาก English แล้ว อยู่ใน batch-034 ถึง batch-045 และตารางใช้งาน

ไฟล์ unreviewed-part-*.json ว่างแล้ว เพื่อไม่ให้ร่างผิดในประวัติงานถูกเข้าใจว่าเป็นคำแปลปัจจุบัน ห้ามนำร่างจาก commit เก่ามาติดตั้ง

รายการต้นฉบับที่ยังกันไว้ย้ายไป ../review/withheld-source.json ครบ พร้อมเหตุผล ไม่รวมในตารางใช้งาน

การใช้เครื่องมือช่วยร่างก่อนหน้านี้เป็น English สาธารณะ → Thai ระหว่างจัดทำงาน ไม่ใช้ Thai เก่าและไม่ได้เปิดแปลออนไลน์ในเกม รอบนี้เขียนใหม่/แก้และตรวจจาก English ไม่อนุมัติร่างเครื่องมือโดยอัตโนมัติ
